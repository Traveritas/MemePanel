# 10 复古像素 RETRO-PIXEL — System 7 / Win95 的 Charm（GDI 的主场）

**概念**：1990 年桌面美学的真心致敬（不是讽刺）：1px 黑边框、硬直角、斜面按钮、条纹标题栏、点阵质感。GDI 原生就是干这个的——这是十个变体里唯一「技术降维反而出彩」的方向。参考：Mac System 7、Windows 95、Hyperscript Card、Kazuo（pixel art 工具）、modern retro 风（Lume/Dunnet 复古 UI 潮）。

## Tokens

- 面板底：**不透明**经典 Mac 浅灰 #DDDDDD（或 Win95 #C0C0C0——选 Mac #DDDDDD 与 05 瑞士白区分），ULW 仍可用（alpha 全 255）
- 边框：面板外 2px 纯黑硬边 + 内 1px 白高光（上左）+ 1px 暗 #808080（下右）——经典 double-bevel；圆角 0
- 标题栏：顶部 26px **水平条纹带**（黑白 2px 相间，System 7 风格）上叠黑色标题文字「 MemePanel 」+ 右端条纹中一个小方块关闭钮（黑边白底，hover 黑底）
- 字体：全站 `Tahoma` 12px / 小字 10px（点阵感）；标题栏文字 `Tahoma` bold 12px；计数 `Consolas`
- 强调：**Mac 系统蓝 #0000FF**（纯蓝！激活标签/选中框）+ 警示红 #FF0000（删除武装）
- **斜面按钮**（关键工艺，纯 GDI+ 四条边画）：常态 = 灰底 + 上左 1px 白 + 下右 1px 黑；按下/激活 = 反转（上左黑、下右白）+ 底色 #BBBBBB；hover = 底色 #E8E8E8 + 外 1px 黑点线框（focus ring 之意）

- 网格 = **表格**：cell 间 1px 黑线（画在底图或每帧画线，注意性能——底图预渲染网格线，图片按格贴）。
- hover：蓝 2px 框（扩 1px 不遮图）+ 底部 Mac 风状态条（黑底白字 9px Tahoma）。
- 滚动条 = **真 Win95 滚动条**：track #E0E0E0 + 竖向刻度线、thumb 斜面灰块带 3 条刻痕线、上下箭头三角（GDI+ 三角形路径，黑）。
- 大图预览 = 「浮窗」：白底 + 黑 2px 边 + 标题条（条纹 + 小标题「Preview」）——一个 mini 窗中窗！
- GIF 角标：黑底白字方块「GIF」8.5px。

## 管理模式

大格表格 + 选中 = 蓝底反白（Mac 文件选中式：整格蓝 α200 + 文件名反白）；按钮全斜面；武装删除 = 红字红框闪烁感（静态红底白字）。

## 验收

- 标题栏条纹（y 向 2px 周期黑白交替采样）。
- 斜面按钮四边可辨（按钮上缘白线、下缘黑线）。
- 网格 1px 黑分隔线 + 0 圆角。
- 滚动条带 thumb 刻痕 + 箭头。
- 与 05 瑞士的区分：05 是白底现代网格，10 是灰底拟物斜面+条纹标题栏。

# 04 杂志版式 EDITORIAL — 排版即界面（黑白的报纸秩序）

**概念**：把表情面板做成一本设计杂志的图片索引页：强烈的字号层级、发丝线（hairline）分隔、超大衬线标题、图注式元数据。黑白 + 唯一正红。参考：Monocle、Wallpaper*、瑞士之外的英美编辑设计、报摊杂志的「Contents」页。

## Tokens

- 面板底：不透明白偏灰 #F4F3F0（纸感）或深炭 #17171A——**你选深炭版**（与其余浅色区分）：rgba(24,24,27,0.96)
- 边框：**无圆角**（rad 全部 0 或 2）+ 1px rgba(255,255,255,0.14) 外框 + 内部大量发丝线 rgba(255,255,255,0.10)
- 正红 ACCENT #E0281E（仅用于：激活下划线、悬停标记、页码、选中）
- 字体：超大标题 `Georgia`（衬线，斜体能用更佳——GDI+ 无斜体变体就用常规+小字号大写）、标签 `Segoe UI` 全大写 + 字距（GDI+ 无 letter-spacing API——用 `GdipMeasureString` 逐字手动绘制，或接受无字距改用小字号大写）、图注/文件名 `Segoe UI` 9px、页码/计数 `Consolas`
- 层级示例：「 表情索引 」标题 Georgia 26px vs 标签 10px 大写 vs 图注 9px——三级字号比 ≥ 2.5:1

## 结构（大改，这是本变体的灵魂）

```
┌──────────────────────────────────────────────┐
│ 表情索引                    Vol.42 · 九月号   │  标题行：Georgia 大字 + 右侧期刊式卷号（Consolas）
│ ──────────────────────────────────────────── │  发丝线
│ ⌕ 搜索 ______________________        ✕ 关闭  │  搜索：下划线式（editorial 的填空线）
│ ──────────────────────────────────────────── │
│ 全部    动物    猫猫                          │  标签：无胶囊！大写小字 + 激活=正红下划线 2px
│ ──────────────────────────────────────────── │
│ 01 ⬒⬒⬒  02 ⬒⬒⬒  03 ⬒⬒⬒  04 ⬒⬒⬒          │  网格：每格**下方图注**（编号+文件名 9px），
│    caption caption caption caption            │  图片带 1px 白 α20 描边方角
│ 05 ...                                       │
│ ──────────────────────────────────────────── │
│ fig. 05 — cat-shock.jpg · 动物        042     │  footer：fig. 图注格式 + 右对齐总页码
└──────────────────────────────────────────────┘
```

- 网格改为**带图注的图片行**：cell 56px + 下方 18px 图注区（`01` Consolas 红/白 + 文件名截断），行列间距比现版大 2px（发丝线美学的呼吸感）。
- hover：图片描边转正红 + 图注编号转红 + **无任何发光/上浮**（editorial 不动效，只有排版状态切换）。
- 大图预览：方角 + 2px 白边（宝丽来衬纸感）+ 底部图注条（fig. XX — 文件名）。
- 标题行「Vol.42」用实际库数量动态（共 N 张 → No.N）。

## 管理模式

工具行做成杂志的「栏目条」：大写小字按钮 + 竖线分隔（ 重命名 | 删除 | 去重 | 修后缀 ），hover = 红色下划线；武装删除 = 红底白字。

## 验收

- 三级字号层级在截图中可辨（探针：标题区文字高度 ≥ 24px，标签 ≤ 12px）。
- 发丝线在标签行上下各一条（采样 y 方向 alpha 突变）。
- 全角零圆角（面板四角采样为直角过渡）。
- 正红像素只出现在指定五处。

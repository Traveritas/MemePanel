# 05 瑞士网格 SWISS — 国际主义风格（网格的绝对秩序）

**概念**：International Typographic Style：数学网格、左对齐的一切、无衬线大字、黑白 + 正红、零装饰零阴影零圆角。界面看起来像 Josef Müller-Brockmann 的音乐会海报被做成了工具。参考：Vignelli、瑞士铁路时刻表、Figma 的早期官网。

## Tokens

- 面板底：纯白玻璃 rgba(250,250,249,0.96)（浅色！）——与 03 宣纸墨区分：无暖调、无噪点、冷而准确
- 边框：rad=0 全直角；外框 1.5px #111；内部网格线 1px rgba(17,17,17,0.15)
- 墨黑 #111111 文字；正红 #FF2B1E（仅激活态与 hover 指示）
- 字体：全站 `Segoe UI`（唯一字体家族，靠字重/字号分层）；标题 FW_BOLD 大写；正文 FW_NORMAL；计数用同字体 tabular（接受非等宽）
- **网格线是主角**：标签行与网格之间、网格列之间都有可见 1px 线（列间线只画在格子之间，不穿透图片）

## 结构（网格可数、对齐可验）

```
┌────────────────────────────────────────────┐
│ MEMEPANEL                        42 BILDER │  标题行：黑体大写标题 + 右对齐计数（红）
│ ⌐==========================================│  1.5px 黑粗线（标题下的横梁）
│ [ 搜索 ____________________ ]          ✕   │
│ ALLE  TIERE  KATZEN                        │  标签：大写、左对齐排列（德语式命名！中德混排：
│ ────────────────────────────────────────── │   全部→ALLE 动物→TIERE 猫猫→KATZEN）
│ [img][img][img][img][img][img][img][img]    │  网格：图片方角、0 间距（图片紧贴成墙）或 1px 线隔
│ [img][img][img][img][img][img][img][img]    │  hover：格子被红色 2px 边框「框选」+ 左上角红色
│ [img][img][img][img][img][img][img][img]    │  编号数字（Helvetica Moment）
│                                            │
│ 42 / 42                                    │  footer：左文件名 · 右分页计数（红色当前页）
└────────────────────────────────────────────┘
```

- **图片墙密排**：cell 间距 0 或 1px 线，网格视觉上是一整面墙（与 04 的图注行区分开）。
- hover：被选格四周 2px 红框（向外扩，不遮挡图片）+ 左上红底白字编号 + 名字条改为**格子下方红字一行**（瑞士海报风，无渐变遮罩——白底黑字反过来：底部 16px 白条 α90 + 文件名黑字 9px）。
- 激活标签：黑色实底白字方块（直角）+ 前置红色小方块 6×6px。
- 搜索框：直角白底 + 1.5px 黑下边线；caret 红色 2px 方块（终端块状光标）。
- 滚动：右缘一条 4px 黑色实心条（无圆角），thumb 纯黑，track rgba(17,17,17,0.08)。

## 管理模式

大格同样密排；选中 = 红 2px 框 + 左上红方块编号；按钮 = 黑边直角方块（hover 黑底白字）；武装删除 = 红底白字直角。

## 验收

- 直角（四角采样）、粗横梁线（标题下 ≥1.5px 全黑横线）、网格线可见。
- 红色只出现在：hover 框/编号、激活标签前块、caret、当前页码、武装删除。
- 左对齐可验：标题、标签、搜索、footer 文字左缘 x 相同（±2px）。
- 与 03 的区分：无暖白、无楷宋字体、无圆角、密排图片墙。

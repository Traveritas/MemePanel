## 结构改动（相对 base）

- `panel_layout`：搜索行 40px 药丸 + 30px 圆形关闭；标签行 h28；最近行 64px 大圆格（圆角 18），左端薄荷果冻心形图标（GDI+ 双圆瓣+三角矢量）；网格 56px/圆角 16；管理模式操作行 h32 果冻药丸、96px 大格/圆角 18。命中矩形（recent/chip/grid/btn/close）全部与绘制同源，交互链未动。
- `gen_base`：改为紫夜垂直渐变 + 奶油/草莓双柔光 + 1.5px 奶油亮边（半径 22）。
- 标签胶囊：`jelly_pill`（果冻三件套）；激活 = 糖果色实底 + 白字 + 同色 glow + 右侧**加深糖果色计数徽章**（白字 9px，数量 = 该标签条目数 / 全部 = 库总数）。
- 搜索框：药丸内凹（紫黑 α200 + 顶暗线/底线亮线），薄荷糖果放大镜（2.2px 粗线）；关闭按钮 hover = 草莓实底果冻 + 白 X + 柔光。
- 大图预览：圆角 20 + 6px 奶油白糖纸边 + 内衬紫夜深底 + 外圈激活色 glow。
- footer：hover 文件名 = 糖果色小药丸标签片（α200 + 白字）。
- 管理模式：选中 = 糖果色勾选气泡（左上圆 + 白勾 2px）+ 2px 描边 + 内凹暗/亮线；按钮中性奶油果冻，「删除」草莓系果冻，武装 = 草莓实底 + 白字 + glow。
- 托盘图标：紫夜糖壳 + 薄荷边 + 白笑脸 + 草莓腮红。

## 重要修复（上游隐患，非本变体引入）

1. **`GdipCreateLineBrushI` 在本机返回 `NotImplemented(6)`**（`GdipCreateLineBrush` 浮点版同样）——所有线渐变填充被静默吞掉（base 的激活胶囊渐变、hover 名字条纱底其实从未渲染过）。本变体改用 `vgrad_fill`（逐 1px 实心条带 + `GdipSetSolidFillColor`，已按 SDK 签名增补进 `gp.h/gp.c` 绑定），视觉等效、开销可忽略。
2. **`g_footer.left/right` 从未赋值**（base 遗留）→ footer 零宽，hover 文件名与管理状态行整条不可见。已在 `panel_layout` 补齐左右界。
3. 演示数据 `out/index.bin` 丢失了标签（nTags=0，与 GUIDE 描述不符）→ 重新植入：动物(0)=bit0 共 38 张、猫猫(1)=bit1 共 4 张（cat-*）。`store_scan` 会保留加载到的标签，后续 -shot 运行不会丢。

## 已知不足

- 条带渐变比单个 LineBrush 调用多十几倍小填充调用（每胶囊约 20 条 1px 带），静态底图仍走 memcpy 预渲染，帧预算内无压力，但属于用调用量换兼容性。
- 心形为双圆+三角近似，20px 下可辨但不如贝塞尔圆润。
- 激活胶囊计数徽章圆径固定 15px，>2 位数（100+）会挤；演示库 42 张无碍。
- 关闭按钮常态刻意低调（hover 才草莓实底），远看存在感弱。
- 深色缩略图上的 hover 提亮（α46 白）在个别图上不够显著（暗带与描边补足区分度）。

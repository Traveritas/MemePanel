# 07 果冻糖 CANDY — 软糖质感（多巴胺配色）

**概念**：软 UI / candy：果冻按钮、糖果色标签、圆滚滚的一切、受光面/背光面的立体感。表情包是快乐的东西，界面也可以理直气壮地可爱。参考：软糖拟物、iOS 早期的圆凸按钮、Duolingo 的配色勇气、Panic 公司的 Playdate 界面。

## Tokens

- 面板底：奶油暗紫 rgba(52,44,72,0.94) 顶 → rgba(38,32,54,0.92) 底（紫夜色，让糖果色跳出来）
- 圆角：外壳 22、格子 16、胶囊 999、按钮 999（药丸）
- 强调色**按标签分配糖果色**（核心机制！）：每个标签一个专属色（动物=蜜橙 #FFA94D、猫猫=草莓 #FF6B9D、全部/默认=薄荷 #4DD8A8、下一个标签=柠檬 #FFD43B……MP_MAX_TAGS 内循环 6 色板），激活胶囊 = 该标签糖果色实底白字 + 同色 glow；hover 格子边框用**当前激活标签的糖果色**（无激活=薄荷）
- 文字：主 #FFF8F0（奶油白）、次 rgba(255,248,240,0.6)；字体 `Segoe UI` 圆润（或 `Tahoma` 更钝更萌），标签字号 12.5px 略大
- **果冻立体件**（预渲染，关键工艺）：
  1. 按钮/胶囊：底色 + **顶部 45% 高度的白渐变提亮**（α 从 0.30 到 0，模拟果冻上弧受光）+ 底缘 2px 同色加深带（暗 25%）+ 1.5px 描边（同色 light 20%）
  2. 格子：常态奶油玻璃 α0.05；hover = 果冻鼓起：提亮 0.18 + 底缘加深带 + **下移 1px 的软影**（预渲染 2px 黑 α40 模糊条，注意 bleed 只有 3px——阴影画在格子自身底边内 1px 处，不外溢）
  3. 按压感：active 态（选中）= 提亮消失 + 内凹：顶缘 1px 暗线 + 底缘 1px 亮线（反转）

## 结构

- 布局保持三段式，但**最近行格子更大更圆**（64px、圆角 18）并带数字气泡回归？——不，数字键已删（用户决定），改成最近行左端一个**果冻心形/星形小图标**（GDI+ 矢量画，薄荷色）标识「最常用」。
- 标签胶囊：药丸形果冻按钮，激活时旁边弹出一个**糖果色小圆点计数徽章**（该标签下的数量，白字 9px）。
- 搜索框：圆角 999 药丸 + 内凹（比面板暗 + 顶缘 1px 暗线）；放大镜改**糖果放大镜**（薄荷色圆 + 糖果柄，2px 线宽更卡通）。
- 大图预览：圆角 20 + 6px 奶油白「糖纸边」+ 外圈同激活色 glow。
- footer hover 文件名：改**糖果色小标签样式**（圆角小片 α200）。

## 管理模式

大格圆角 18；选中 = 糖果色勾选气泡（左上角圆形色块 + 白勾）+ 圆形描边；按钮 = 果冻药丸；删除武装 = 草莓色实底 + 白字。

## 验收

- 至少 3 种糖果色同屏（标签行 + 激活态）。
- 果冻件有可辨立体感：胶囊顶部亮、底部深（同色采样亮度差 ≥30/255）。
- hover 格子有底缘暗带 + 提亮。
- 整体氛围与 base 严肃玻璃形成鲜明「快乐」反差。

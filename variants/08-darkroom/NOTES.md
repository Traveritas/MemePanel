## 结构改动（对 main.c）

- **gen_base**：重写——哑光炭均匀填充（去掉 164° 渐变/径向高光）；GDI+ 绘制胶片盒标签条（path_top_round 仅上角圆）+ 标签文字（烤进底图）+ 左缘齿孔带 + 分隔刻线 + 相纸切边。外壳圆角 18→6。
- **panel_layout**：内容左界让开齿孔带（contentL = panel.left + S(22)+S(12)）；检索行内嵌到标签条（S(24) 高暗条 + S(24) 关闭钮）；新增 g_rowH 行距 = 胶片边×2 + 图 + 帧编号条 + 行隙（速发 56px 格 / 管理 96px 格）；网格右缘让开 S(20) 给刻度尺；footer 左右界显式设定。
- **cell_from_point**：行距改用 g_rowH（点击命中含编号条整行，与绘制一致）。
- **film_frame / matte_skin / grease_circle / grease_x**：替换 glass_cell。grease_circle = 两段弧（15°..175° + 195°..355°，两处 ~20° 缺口，0° 方向必缺）+ 圆头笔帽 + 椭圆略下坠。
- **draw_grid**：底片格 + 帧编号（idx+1 三位递增；GIF=琥珀）；hover = grease 红圈（取消名字条，信息移到 footer）；mgr 选中 = 大红圈 + 右上角琥珀手绘 X；滚动条改「胶片边缘刻度」（右缘短横刻度 + 琥珀窗口高亮段）。
- **draw_recents**：REC 暗黄小标 + 同款底片格（无编号条）；hover 同样红圈。
- **draw_chip**：哑光小体字胶囊（无光晕）；active = 做旧纸黄打印标签感。
- **draw_search_box**：嵌在黄褐带内的哑光暗条 + b/w 胶片格图标（两格小矩形）+ 暗黄 caret / IME 下划线；关闭钮 = 描线方块。
- **draw_footer**：1px 台面刻线 + 悬停大写文件名·标签（wupper_ascii）+ 右侧常驻 ROLL/FRM 胶卷计数。
- **draw_preview**：放大镜语义——外扩 5px 相纸白框（宝丽来）+ 白 2px 图边 + 左上红色 loupe（圆+柄+十字）+ 右下十字准星两笔。
- **draw_mgr / draw_mgr_button**：暗黄描边哑光块；危险悬停 = grease 红描边；武装删除 = 琥珀实底近黑字；状态行「DARKROOM:」琥珀前缀 + 右侧 SEL/ROLL 计数。
- **make_app_icon**：托盘图标改哑光炭 + 黄褐带描边 + 三齿孔 + 白笑脸。
- **gp.h/gp.c**：按 SDK gdiplusflat.h 原始签名增补 `GdipDrawArcI`、`GdipSetPenLineCap197819`（圆头笔帽）。
- 空态：未曝光底片格（描线框 + 「000」编号）+ 提示文案。

## 已知不足

1. **刻度尺（胶片边缘滚动指示）在演示数据下不出现**：2560×1600 屏两模式可见格数（78/55）都 ≥ 42 张，不触发滚动。逻辑已实现且与 g_first/vis 联动，但只能靠代码走查保证（无头数据无法撑出滚动量）。
2. **本变体 out/index.bin 实际无标签**（nTags=0，二进制内无「动物/猫猫」字符串），标签行只显示「全部」——数据问题非代码问题；多胶囊绘制走同一 draw_chip 路径。
3. 个别窄长比例的表情图在 contain-fit 下上下/左右留黑（黑来自底片格填充），呈现为「黑底窄条」——这是底片格语义的自然结果。
4. hover/选中红圈在斜角方向会切入图片四角上方（椭圆内接于矩形的几何必然）——刻意保留：真 grease pencil 圈选本来就会压过相片角。
5. 预览相纸白框右缘与刻度尺有 ≤5px 重叠区（仅滚动时可见刻度时发生），放大镜「压在印样上」语义上可接受。

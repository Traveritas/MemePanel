# 03 宣纸墨 PAPER-INK — 交付说明

STATUS: DONE

## Token 摘要

| 项 | 值 |
|---|---|
| 面板底 | 暖白宣纸垂直渐变 rgba(248,246,240,.93) → rgba(238,235,226,.90)，无径向高光 |
| 纸纤维 | ~2% 像素 ±3 亮度（xorshift32，gen_base 生成期一次，不进每帧路径） |
| 边框 | 1px 墨 rgba(60,50,40,.18) + inset 顶线 rgba(255,255,255,.8) |
| 圆角 | 外壳 14 / 格子 8 / 书签胶囊 4（brief 的「胶囊 999」被墨书签无底常态取代，激活态按印章 spec 用 4px） |
| 墨色 | 浓 #33302B；次 α158-165；弱 α97-130 |
| 印章红 | #C3402B（唯一强调色，无渐变对、无发光） |
| 字体 | 标签/按钮/空态 `KaiTi` S13（比现版大 1px）；正文/文件名/状态 `SimSun` S13/S11/S9；计数 `Consolas` S10；「搜」字 `KaiTi` S12 |
| 悬停格 | 底 rgba(195,64,43,.06) + 边框印章红 α120 1.2px；名字条 = #33302B 墨色渐变遮罩（α0→215）+ 暖白小字 |
| Caret | 墨色竖线 2px；IME 组合下划线墨色 α175 |

红的使用纪律（五处 + 两粒句读点）：激活胶囊印章 / 聚焦搜索底线 / hover 边框（含淡红底）/ 武装删除实底 / 选中双勾角标+红描边；另按 brief 结构条款保留了最近行行末小红点与关闭圈 hover 朱砂点（2-3px 句读级）。

## 改动清单（src/main.c）

- tokens 区重写（T_INK_*/T_ACC_*、C_INK/C_ACCENT/C_PAPER_TXT），删除 ACCENT2。
- `gen_base`：宣纸渐变 + 纸纤维噪点 + 墨边（S(14) 圆角）+ 白 inset 顶线；删除 164° 轴向与径向高光。
- `glass_cell` → `paper_cell`（白卡纸底/红晕 hover/红实底三态）；删除 `draw_glow` 与全部 glow 调用（浅色纸面不发光）。
- `draw_search_box`：无框化，底部 1.5px 墨线 / 聚焦 2px 朱砂线（新增 `g_focus`，show/SETFOCUS/KILLFOCUS 维护，无头默认聚焦）；「搜」字墨记替代放大镜；关闭 = 空心墨圈 ○，hover 圈心朱砂点。
- `draw_recents`：左侧 2px 墨 α40 册页装订线 + 行末红点句读；格 S(8)。
- `draw_chip`：墨书签常态（无底纯文字，hover 转浓）；激活 = 印章式红底白字圆角 4px + 右上 45° 暗红 α90 凹痕短线。
- `draw_empty`：「拖入表情，落纸为安」+ 淡墨横线（α45）。
- `draw_grid`：格 S(8)、选中 = 红描边 1.6px + 红底白双勾角标；GIF 徽标浓墨底暖白字；滚动条墨 α80。
- `draw_footer`：宋体次墨 α158。
- `draw_preview`：裱卡（更白纸 α242 + 墨发丝边 α60 + 圆角 8）。
- `draw_mgr_button`：墨线描边书签（常态）/ 墨底白字（hover）/ 印章红实底（武装删除）；命中 rect 仍按武装文案宽度固定。
- `draw_mgr` 状态/计数色调整为次墨/弱墨。
- `panel_layout`：**修复继承 bug** — `g_footer.left/right` 从未赋值（静态零），管理模式状态行 rect 宽度为负导致文字从不显示；现设为面板内边距范围。
- `make_app_icon`：宣纸墨风（暖墨底角 + 纸圆角方 + 墨笑脸 + 朱砂小印）。
- entry 字体表：KaiTi/SimSun/Consolas 体系（新增 `g_fGlyph`）。

数据侧：本变体 `out/index.bin` 实际 nTags=0（与 GUIDE 描述不符，无「动物/猫猫」），已按 store.c 的 MPX1 格式重写补入两标签并给 42 条目打标（cat-* → 猫猫，其余 → 动物），原文件备份为 `out/index.bin.bak`。仅影响演示数据展示，无代码耦合。

## 已知不足

- 预览大图卡被方形缩略图填满时，裱卡只露出边线（数据的图多为方图）；非方图会显出白卡留边。
- 「胶囊 999」token 因标签常态改为无底墨书签而实际未使用（激活印章按 spec 用 4px）。
- 搜索框无视觉边框，其 48px 高的命中区仍是隐形热区（点击无反馈但也不误触，布局未动以保证交互稳定）。
- 印章红验收条款之外存在两处 brief 明文要求的小红点（最近行末句读点、关闭 hover 朱砂点），已按结构条款保留并控制在 2-3px。
- 纸纤维噪点每次 rebuild_surface 重新随机（xorshift 固定种子，同尺寸内稳定；不同会话间图案一致因为种子固定）。

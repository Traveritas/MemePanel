# 09 指令面板 PALETTE — 布局革命（Raycast/Spotlight 式列表）

**概念**：唯一动**信息架构**的方向：网格 → **垂直结果列表**。像 Raycast/Alfred/Spotlight：搜索是主角（顶部大命令行），结果是高信息密度的行（缩略图 + 名称 + 标签 + 元数据），键盘优先的肌肉记忆。呼出即搜索、下箭头浏览、回车发送——比网格更贴合「速发」本质？让截图说话。参考：Raycast、Alfred、macOS Spotlight、Linear 的命令面板。

## Tokens

- 面板底：深空灰玻璃 rgba(30,32,38,0.95) 顶 → rgba(20,21,26,0.93) 底
- 宽度策略**改窄**：速发模式 38% 宽 × 58% 高（竖长条！这是列表布局的正确比例），管理模式保持 60×66（管理仍是网格更合理）
- 圆角：外壳 16、行 10、胶囊 999
- 强调：电紫 #8B7CFF → 青 #5CE1E6（激活/选中渐变对，只给选中行与激活胶囊）
- 字体：名称 `Segoe UI` 13px、元数据 10.5px 次色、搜索行 `Consolas` 15px（命令感）+ `▍`块状 caret
- 列表行（核心件）：高 56px——左 44px 圆角缩略图（rad 9）+ 中列（名称 13px 主色 + 下一行「标签 · 220KB · GIF」9.5px 次色）+ 右侧（选中行显示 `↵ 发送` 提示，Consolas 10px α150）；选中行 = 渐变底 α60 + 左缘 3px 电紫竖条 + 缩略图亮边

## 结构

```
┌──────────────────────────────┐
│ ⌕ dance.gif▮                 │  搜索即命令行：大号、无框、底部分隔线（聚焦感靠 caret + 底部 2px 渐变线）
├──────────────────────────────┤
│ 最近                         │  分节标题（小字大写次色）——仅最近节有
│ [img] dance.gif     ↵ 发送   │← 选中行：渐变底+左紫条
│ [img] cat-shock.jpg          │
│ 全部 · 动物 · 猫猫           │  标签行：小胶囊（密排、可滚动省略）
│ [img] capybara.jpg           │
│ [img] chicken-v2.jpg  GIF    │
│ [img] dog-sideeye.jpg        │
│ ...（滚动）                  │
├──────────────────────────────┤
│ 42 项 · ↑↓ 浏览 ↵ 发送       │  footer：快捷键提示（功能文案，终态常驻）
└──────────────────────────────┘
```

- **选中态即 hover 态**：鼠标悬停行 = 选中（同步 g_hover）；方向键 ↑↓ 移动选中（改 WM_KEYDOWN：替换现网格翻页逻辑为行移动 + 滚动跟随 g_first 按行使 viewport）。
- 大图预览：**贴右侧弹出**（列表右缘外贴一张 168px 图，像 Raycast 的右栏预览），280ms 逻辑保持。
- 命中检测全部按行 rect（`cell_from_point` 改 `row_from_point`），Enter 发送选中行、点击行发送。
- 空态：「输入以搜索 · 拖入图片导入」。

## 管理模式

保持网格（管理要看得多），但皮肤跟随：选中 = 渐变底 + 左紫条 + 勾角标；按钮药丸渐变。

## 验收

- 速发面板是**竖长条**（宽 < 高，宽 ≈ 38% 屏宽）。
- 列表行结构可辨：缩略图列 x 对齐、名称列、右侧提示。
- 选中行渐变底 + 左缘紫条（探针：行左缘 3px 竖条采样为电紫）。
- footer 快捷键提示文字存在。

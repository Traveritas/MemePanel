# 09 指令面板 PALETTE — 交付说明

STATUS: DONE

## 概览

唯一动信息架构的变体：速发面板从网格改为 **Raycast/Spotlight 式垂直结果列表**。
竖长条面板（宽≈38%屏宽、高保证>宽）+ 顶部无框搜索命令行（Consolas 15px + 块状 caret
+ 底部 2px 电紫→青渐变线）+ 高信息密度列表行 + 贴面板右缘外弹出的 168px 预览卡。
选中即 hover（鼠标悬停行=g_hover，方向键↑↓移动选中并滚动跟随，Enter 发送选中行）。
管理模式保持 96px 网格，皮肤跟随（渐变选中底+左紫条+勾角标+药丸按钮）。

- exe：`out/MemePanel.exe`（63488 字节，远低于 90KB 上限；MSVC 构建通过）
- 截图：`shot_panel.png` / `shot_hover.png` / `shot_mgr_sel.png`（本机 2560×1600 @120dpi，
  速发窗 1205×1050，面板 972×1042）

## 结构改动（相对基线 main.c）

- **布局**：新增 `palette_layout()`（速发分节每帧按搜索/筛选状态重排：搜索中或筛选时隐藏最近节）、`quick_size()/quick_win_w()`（竖长条尺寸策略：38% 宽，高 = max(58% 屏高, 宽+S(56))——BRIEF 的 38×58 在 16:9 屏上宽>高，为满足「宽<高」验收做了拔高）。`panel_layout` 速发分支：面板=窗口左主体，`g_preview` 移到面板右缘外垂直居中。
- **绘制**：`draw_search_box` 重写为命令行；新增 `draw_list_row`/`row_meta`/`draw_palette`（最近节+胶囊行+结果行+滚动条）；`draw_recents`/旧速发网格删除；`draw_grid` 仅管理模式使用且选中装饰改为图上绘制（方图会盖住底面装饰）；`draw_footer` 速发常驻快捷键提示、管理状态行移入。
- **交互**：新增 `row_from_point`/`list_from_point`/`select_row`/`sel_follow_view`；WM_KEYDOWN：Enter 发送 g_hover 选中行（refilter 后默认选中第 0 行=呼出即回车直发），↑↓=行移动+滚动跟随+预览定时重启+GIF 动画请求，PgUp/PgDn=按视口翻页；滚轮=3 行步进并把选中拉回视口；管理模式保留原网格翻页。
- **-shot**：速发窗口含预览区宽度；`-hover N` 语义=结果列表第 N 个可见行（管理=第 N 大格）；新增导出 `shot_layout.txt`（全部关键矩形坐标，像素探针的确定性锚点）。
- **gp.h**：新增 `GP_WRAP_TILE=0` 枚举并加注释。
- **out/index.bin**（演示数据，非代码）：注入了 GUIDE 声称存在但实际缺失的 动物/猫猫 两个标签（capybara/dog/chicken→动物，cat→猫猫；工具 `inject_tags.ps1`）。

## 修复的基线潜伏 bug

1. **GdipCreateLineBrushI + WrapModeClamp 返回 InvalidParameter(2)**：基线所有线渐变
   （激活胶囊/武装按钮渐变底）从未渲染过（静默失败）。改用 WrapModeTile（填充域=渐变
   轴跨度，视觉等同 clamp）。已用状态探针定位并复测。
2. **g_footer.left/right 从未赋值**：基线 footer 文本画在 0 宽矩形里不可见。两个分支
   均已补齐（速发/管理）。

# 08 底片印样 DARKROOM — 摄影师的工作台（contact sheet）

**概念**：把表情库做成暗房里的底片印样（contact sheet）：胶片齿孔、帧编号、 Grease pencil 圈选标记、哑光相纸。图片是绝对主角，界面是工作台。参考：真正的 35mm contact sheet、暗房红灯区、Ansel Adams 工作台、电影胶片 Timer。

## Tokens

- 面板底：哑光炭 rgba(27,27,29,0.96)（无玻璃通透感，哑光相纸）+ 顶部**胶片盒标签条**：一条高 26px 的深黄褐色带 rgba(58,48,30,0.9)，上面写「MEMEPANEL · ISO 42/36」风格文字（Consolas，做旧纸黄 #D8C9A3）
- 齿孔：面板**左缘**一条 22px 宽的胶片齿孔带——上下连续的圆角方孔（8×6px，rgba(0,0,0,0.55) 孔 + 1px 亮线 α25 孔缘，每 14px 一个，预渲染到底图）
- 圆角：外壳 6（克制）、格子 2（近方角——底片格是方的）
- 文字：帧编号 `Consolas` 8.5px 暗黄 #B8A87F；主文字 rgba(232,228,218,0.9)；琥珀红 GREASE #FF5A3C（圈选/警示）
- 格子：底片格——图片上下各 3px 「胶片边」暗带（黑 α200）+ 1px 亮线框 α30，图片本身全彩（正片冲洗完成感）

## 结构

```
┌─────────────────────────────────────────────┐
│▌▌ MEMEPANEL · ISO 042 ✦  36 EXP     [⌕___✕] │ 胶片盒标签条（黄褐带）
├──┬──────────────────────────────────────────┤
│▨ │ (全部)(动物)(猫猫)                         │ 齿孔带│标签行：小体字胶囊（哑光，无光晕）
│▨ │ 001 ⬒⬒⬒  002 ⬒⬒⬒  003 ⬒⬒⬒  004 ⬒⬒⬒     │ 网格：**每格下缘 12px 帧编号条**
│▨ │    001       002       003       004       │ （001/002… Consolas 暗黄，GIF 帧 = 编号琥珀色）
│▨ │ 005 ⬒⬒⬒  006 ⬒⬒⬒  007 ⬒⬒⬒  008 ⬒⬒⬒     │
│▨ │                                           │
│▨ │                    ╭──────────╮           │ 大图预览：**放大镜**语义——白色 2px 边
│▨ │                    │  big img  │           │ + 外扩 3px 相纸白框（宝丽来式）+ 右下
│▨ │                    ╰──────────╯           │ 「loupe」十字准星两笔
│▨ │ CAT-SHOCK-V3.JPG · 动物          ROLL 042 │ 状态行：文件名大写 + 右侧胶卷计数
└──┴──────────────────────────────────────────┘
```

- hover：**Grease pencil 圈选**——格子四周画一个手绘感红圈（GDI+：椭圆路径近似圆圈 + 线宽 2px + α200 + 起点处小缺口——两段弧留 15° 缺口，像真笔圈画），名字不做条，改在 footer 显示（工作台语义：信息集中在台面下缘）。
- 大图预览 = 放大镜落在印样上：白相纸框 + 预览图 + 左上角红色小loupe图标（圆+柄+十字）。
- 搜索框：哑光暗条 + 暗黄 caret；放大镜改**暗黄小写 b/w 胶片格图标**（两格小矩形）。
- 滚动条 = 右缘「胶片边缘刻度」：连续短横线刻度 + 当前窗口范围用琥珀色高亮段（像胶片尺）。

## 管理模式

选中 = grease pencil 大圈 + 右上角手绘 X（两笔琥珀线）；按钮 = 暗黄描边哑光块；武装删除 = 琥珀实底；状态行前缀「DARKROOM:」。

## 验收

- 左缘齿孔带可见且周期正确（y 向采样孔暗/孔间亮的周期）。
- 顶部黄褐标签条 + 暗黄文字。
- hover 红圈：两段弧 + 缺口（不是完整椭圆——探针在圈上取 8 点至少 1 点缺失）。
- 帧编号条：每格下方 Consolas 暗黄编号递增。

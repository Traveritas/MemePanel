# 06 霓虹终端 NEON-TERM — CRT 磷光屏（键盘手的领地）

**概念**：表情库是一台老式磷光终端：近黑屏、磷绿主色、琥珀警示、扫描线、等宽字体、方框绘制字符的界面框。深夜赶稿程序员的肌肉记忆。参考：IBM 3270 终端、CRT 磷光余晖、William Gibson、htop/tmux 美学。

## Tokens

- 面板底：rgba(6,12,8,0.94)（近黑带绿偏）+ **扫描线**：生成期在底图上叠加每 3px 一条 rgba(0,0,0,0.22) 水平线（预渲染，不逐帧）+ 整体轻微磷光辉光（边缘 vignette 绿色 α8）
- 边框：双线框！外 1px #2AFF88 α160 + 内 1px α60，四角用 GDI+ 短线画出「角加强」（十字/缺角风格，像 box-drawing 的 corner joint）
- 磷绿主 PHOSPHOR #2AFF88、暗绿 #16A852、琥珀 AMBER #FFB000（删除/警示）、文字主 rgba(42,255,136,0.92)、次 α0.55
- 圆角：0（终端是方的）
- 字体：**全站 Consolas**（含中文 fallback 到微软雅黑——接受混排），标题行可用 `Impact` 大写玩一行「MEME://TERMINAL」
- caret：**块状光标**（反色块：绿底黑字，10×16px 实心方块，闪烁）

## 结构

```
┌╔════════════════════════════════════════╗─┐
│ MEME://TERMINAL v0.6        [42] ONLINE │  标题条：左「MEME://TERMINAL」+ 右 [计数] ONLINE（绿点闪烁感用 α 静态近似）
╞═════════════════════════════════════════╡  分隔双线
│ > 搜索_                                   │  命令行式：`> ` 前缀绿亮、输入白绿、无框
│ ─────────────────────────────────────── │
│ [ALL] [动物] [猫猫]                       │  标签 = 方括号 token（激活 = 反色绿底黑字）
│ ─────────────────────────────────────── │
│ [01][02][03][04][05][06][07]             │  网格：格子带 1px 暗绿框（α90），
│ ...42 格，GIF 格右下角 `~GIF~` 琥珀小字    │  hover = 亮绿 2px 框 + 整格提亮（磷激发）
│                                          │  + 底部名字条 = `> filename.gif` 绿字黑条
│ READY_                          ▓▓▓░░ 42 │  状态行：左 READY + 块状进度条（滚动位置）
└╚════════════════════════════════════════╝─┘
```

- 搜索行做成**命令行**：`> ` 前缀、输入时尾部块状 caret、无任何框（靠上下双线分区）。
- 悬停大图预览：方角 + 绿色双线框 + 右上角 `VIEW:` 前缀文件名 + 底部帧信息 `42x42 3FR`（GIF 帧数风格化文案，无数据就 `IMG`）。
- 滚动条：右缘琥珀色 `▓▓░` 字符块风（画矩形串，不用字符字面量）。
- **辉光效果**：文字不加辉光（性能），但激活标签/hover 框用预渲染 glow（绿色 peak 0.25）——磷光在「通电」处才亮。

## 管理模式

按钮 = `[重命名] [删除] [去重] [修后缀]` 方括号风（hover 反色；删除武装 = 琥珀反色闪烁感）。状态行前缀 `SYS:`。选中 = 格内画 `X` 记号（琥珀，短线交叉）+ 亮框。

## 验收

- 扫描线可见（y 方向周期性暗纹，探针采样 3px 周期）。
- 双线框 + 角加强在四角可辨。
- 绿色主导 + 琥珀仅在删除/GIF/警示。
- 与 base 的区分度：一眼是「另一台机器」而不是「另一个主题」。

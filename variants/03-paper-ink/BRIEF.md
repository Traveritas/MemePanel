# 03 宣纸墨 PAPER-INK — 唯一的浅色方向（文房气质）

**概念**：宣纸 + 墨 + 印章红。整个面板是半透明白宣纸浮在暗色桌面上（ULW 白底玻璃），文字是墨色，激活/强调是朱砂印泥红。中国文人 UI 但不是国风贴纸——克制、留白、字即是设计。参考：iOS 浅色玻璃、Notion 的秩序感、宋代版式的疏朗。

## Tokens

- 面板底：rgba(248,246,240,0.93) 顶 → rgba(238,235,226,0.90) 底（暖白宣纸）；顶部无径向高光，改为**纸纤维噪点**（生成期随机 2% 概率像素 ±3 亮度，预渲染一次）
- 边框：1px rgba(60,50,40,0.18) + inset 顶线 rgba(255,255,255,0.8)
- 圆角：外壳 14（比现版收敛）、格子 8、胶囊 999
- 墨色：主 #33302B（浓墨）、次 rgba(51,48,43,0.62)、弱 0.38
- 印章红 ACCENT：#C3402B（只有一个强调色，无渐变对）
- 字体：标题/标签行 `KaiTi`（楷体，字号比现版大 1px 显笔势）；正文/文件名 `SimSun`（宋体，衬线的秩序）；计数/等宽 `Consolas`
- 光标：caret 改为**墨色竖线 2px**，无闪烁以外的动效
- 悬停：格子底变 rgba(195,64,43,0.06) + 边框转印章红 α120 + 名字条用**墨色渐变遮罩**（非黑，用 #33302B）

## 结构改动

- 标签胶囊改为**墨书签**：常态 = 无底纯文字（次墨色）+ 底部 3px 空隙；激活 = 印章式：红底白字圆角 4px + 右上角小小的「凹痕」notch（1px 暗红 α90 的 45° 短线，仿印章边缘）。
- 最近行：格子带**册页装订线**——整行左侧一条 2px 墨色 α40 竖线 + 行末小红点分隔。
- 搜索框：无框！只有**底部 1.5px 墨线**（聚焦时转红、加宽到 2px），左侧放大镜改为墨色「搜」字（KaiTi 12px，次墨色）。
- 关闭按钮：空心墨圈 ○（1.5px 墨笔圆），hover 圈内出现红点。
- 空态文案改：「拖入表情，落纸为安」+ 一条淡墨横线。

## 管理模式

按钮 = 墨线描边书签式（无底，hover 墨底白字）；删除武装 = 印章红实底。选中态 = 红色双勾角标 + 红描边。

## 验收

- 面板中心采样应为暖白（R>G>B，R≥230），与暗背景强反差。
- 楷体标签行、宋体正文可辨（探针：文字区存在墨色像素簇）。
- 印章红只出现在：激活胶囊、聚焦搜索线、hover 边框、武装删除、选中角标——五处之外无红。
